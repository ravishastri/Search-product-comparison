## Pricing and plans

- Linear offers a free plan that caps usage at two teams and 250 active issues while allowing unlimited members, and it includes core issue tracking, cycles, projects, and roadmaps. [S32][S35][S69] (date unknown)
- Linear's Basic tier costs $10 per user per month with annual billing and includes unlimited issues, guest access, advanced filtering, and integrations. [S32][S35] (date unknown)
- Linear's Business tier costs $16 per user per month with annual billing and adds priority support, advanced analytics, SAML SSO, and SCIM provisioning. [S32][S35] (date unknown)
- Linear's Enterprise plan uses custom pricing and includes dedicated support, advanced security, and compliance features. [S32][S35] (date unknown)
- According to Spendflo, Linear pricing plans range from $5,000 to $70,000 depending on organizational needs. [S31] (date unknown)
- Factors that affect Linear pricing include the number of teams, required features, and organization size, with discounts available for annual billing. [S31] (date unknown)
- Guest accounts require Linear's Business plan and are billed as regular members rather than at a reduced rate. [S69] (date unknown)
- Some Linear AI features, including coding sessions and loops, consume prepaid AI credits, while the remainder of its AI capabilities are included in standard plans. [S69] (date unknown)
- Plane's managed cloud service starts at $6 per user per month when billed annually. [S53] (date unknown)
- Plane's 10-seat Pro plan costs roughly 40% less than Linear's Basic tier. [S54] (date unknown)
- GitHub's Team plan is priced at $4 per user per month. [S46][S49][S50] (date unknown)
- GitHub's Enterprise plan starts at $21 per user per month. [S46][S49][S50] (date unknown)
- Plane offers a free self-hosted tier with no per-seat cost for teams running the software on their own infrastructure. [S40][S55] (date unknown)

## Competitive landscape

- Linear is intentionally narrow and built for Engineering, Product, and Design teams that want a polished, cloud-hosted service with minimal configuration. [S51] (date unknown)
- Linear offers an interface optimized for keyboard navigation, automated sprint management, and streamlined design. [S2] (date unknown)
- Plane serves Engineering, Marketing, Operations, and Customer Success teams, while Linear targets only Engineering, Product, and Design workflows. [S51] (date unknown)
- Plane is an open-source alternative that supports self-hosting via Docker, and Codegen describes its codebase as MIT-licensed. [S54] (date unknown)
- According to Zoobbe, Plane is licensed under AGPL-3.0. [S60] (date unknown)
- Plane mirrors Linear's core model by using cycles for sprints, modules for epics, and a keyboard-driven interface. [S54] (date unknown)
- Codegen states that Plane's interface is improving but still falls behind Linear in the refinement of keyboard shortcuts and overall responsiveness. [S54] (date unknown)
- Plane provides a spreadsheet view for bulk-editing issues in a table format, a capability reviewers say is not natively matched by Linear or Jira. [S52] (date unknown)
- Plane includes integrated pages tied to projects, which means teams may not need a separate wiki tool for specifications and meeting notes. [S52] (date unknown)
- Hosted Huly has been discontinued and is no longer funded or available, though the software can still be self-hosted. [S11] (date unknown)
- Huly is an open-source platform licensed under EPL-2.0 that combines project tracking, documents, team chat, video calls, and file management. [S56][S59][S60] (date unknown)
- Huly includes two-way GitHub synchronization, built-in video conferencing, and collaborative wiki documents. [S56] (date unknown)
- Huly runs multiple services in Docker containers and is described as more resource-intensive than simpler tools. [S57] (date unknown)
- Huly offers syntax highlighting in code blocks for technical documentation. [S57] (date unknown)
- GitHub Issues integrates tightly with code repositories and mixes timeline data with CI events, pull request reviews, and deployment notifications. [S61][S62] (date unknown)
- Linear's GitHub integration links issues to pull requests and commits and automatically updates issue status as pull requests move from drafted to merged. [S63][S65] (date unknown)
- Linear generates consistent issue identifiers that allow branches or pull requests containing those identifiers to automatically link back to the corresponding issue. [S65] (date unknown)
- Linear maintains a detailed history of every state change, comment, and assignment, which supports automatic generation of standup summaries and sprint status reports. [S62] (date unknown)
- DevToolReviews reports that Linear loads instantly and processes actions in under 100 milliseconds, using aggressive local caching and client-side updates that appear before server confirmation. [S61] (date unknown)
- Jira offers maximum configurability for complex organizations. [S61] (date unknown)
- Plane has a smaller integration ecosystem and more basic reporting and mobile experience than older tools, reflecting its newer market entry. [S53] (date unknown)
- Alfred_ notes that Plane is the only major Linear alternative that allows full self-hosting on a team's own servers at no cost. [S53] (date unknown)
- Linear provides an agent platform and an official MCP server. [S5] (date unknown)
- Linear Agent launched in public beta on March 24, 2026, and can be assigned to issues, added to projects, and used to triage tasks and draft project updates. [S66] (date unknown)
- Linear introduced Shared Skills on June 4, 2026, allowing teams to save and reuse agent instructions. [S66] (date unknown)
- Linear's Coding Sessions became generally available on June 11, 2026, on Basic, Business, and Enterprise plans and allow the agent to generate code using Claude Code and Codex. [S66][S67] (date unknown)
