# Launch brief: Linear

Generated 2026-10-18. Similar products (same category, same target customer): Jira, YouTrack, GitHub Issues.

## Pricing and plans

- Linear offers a free plan for unlimited members, capped at 2 teams and 250 active issues. [S8][S31][S44]
- Linear's Basic plan costs $10 per user per month when billed yearly and removes the issue limit, allowing up to five teams. [S7][S8][S10][S31][S44]
- Linear's Business plan costs $16 per user per month when billed yearly and adds unlimited teams, private teams, guests, Triage Intelligence, Insights, Linear Asks, and support-desk integrations. [S7][S8][S10][S31][S44]
- Linear's Enterprise plan uses custom pricing and is available with annual billing only. [S7][S10][S31]
- Coding sessions and Loops in Linear consume prepaid AI credits. [S31][S44]
- Guest accounts in Linear require the Business plan and are billed as regular members. [S44]

## Competitive landscape

- Linear is described as the fastest, most opinionated issue tracker available, with a keyboard-first interface and automatic sprint management. [S4]
- Linear's API queries reportedly return in 47ms, compared to Jira's 3.2 seconds for identical operations. [S30]
- Linear's interface is described as feeling like a well-designed developer tool rather than enterprise software. [S30]
- Linear addresses backlog rot by introducing incoming task screening and trimming backlog items that remain too long. [S27]
- Linear's AI features prioritize backlogs, auto-generate reports, triage tickets, create issues from Slack conversations, and connect with coding tools. [S28]
- Linear supports two-way issue sync with one repo per team, built-in coding agent sessions on Business plans and above, and an MCP server. [S36]
- Linear integrates with Slack to create issues and sync discussions, and with GitHub to automate pull request workflows, update issue statuses, and sync comments. [S40]
- Linear is positioned as best for most engineering teams, while Jira wins for enterprises needing configurability and GitHub Issues wins for open-source projects. [S39]
- Linear loads instantly, transitions are animated at 60fps, and actions respond in under 100ms through aggressive local caching and optimistic updates. [S37]
- Linear is characterized as fast because it removed choices, while YouTrack is characterized as flexible because it kept them. [S32]
