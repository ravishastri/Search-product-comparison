## 1. Pricing & Plans

### Linear
Linear offers one free tier and three paid tiers billed annually:

| Plan | Price | Key Limits |
|------|-------|-----------|
| **Free** | $0 | Unlimited members, 2 teams, 250 active issues, 10MB file uploads, Agent platform [https://linear.app/pricing](https://linear.app/pricing) |
| **Basic** | $10/user/month | 5 teams, unlimited issues, unlimited file uploads, admin roles [https://linear.app/pricing](https://linear.app/pricing) |
| **Business** | $16/user/month | Unlimited teams, private teams, guest access, Linear Insights, Linear Asks, Triage Intelligence, Zendesk/Intercom integrations [https://linear.app/pricing](https://linear.app/pricing) |
| **Enterprise** | Custom (annual only) | SAML/SCIM, enterprise security, migration support, priority support [https://linear.app/pricing](https://linear.app/pricing) |

Sources note Linear raised prices in 2025 — previously $8 and $14 for Basic and Plus — while expanding the free tier to unlimited members with the 250-issue cap [https://tech-insider.org/linear-vs-jira-2026](https://tech-insider.org/linear-vs-jira-2026).

### GitHub Issues
GitHub Issues is **free with every repository** (public or private). The paid GitHub plans unlock additional collaboration, automation, and security layers that include GitHub Projects (boards, custom fields, roadmaps):

| Plan | Price | What You Get |
|------|-------|-------------|
| **Free** | $0/month | Unlimited repos, 2,000 CI/CD minutes/month, basic Issues & Projects [https://www.spendflo.com/blog/github-pricing-guide](https://www.spendflo.com/blog/github-pricing-guide) |
| **Team** | $4/user/month | Protected branches, required reviewers, 3,000 CI/CD minutes [https://www.spendflo.com/blog/github-pricing-guide](https://www.spendflo.com/blog/github-pricing-guide) |
| **Enterprise** | From $21/user/month | SAML SSO, audit logs, 50,000 CI/CD minutes, advanced security [https://www.spendflo.com/blog/github-pricing-guide](https://www.spendflo.com/blog/github-pricing-guide) |

> **Key distinction:** There is no separate charge for issue tracking itself — it is included in all GitHub plans [https://www.ideaplan.io/compare/github-issues-vs-jira](https://www.ideaplan.io/compare/github-issues-vs-jira).

## 2. Competitive Landscape

| Dimension | Linear | Jira | GitHub Issues | YouTrack |
|-----------|--------|------|---------------|----------|
| **Sweet Spot** | Startups & scale-ups (5–300 engineers) | Enterprises (50–5,000+) | Teams already all-in on GitHub | Dev teams in JetBrains ecosystem (10–500) |
| **Core Philosophy** | Speed over features; opinionated workflow | Configurable for any process | Code-native, minimal friction | Developer ergonomics; powerful query language |
| **Speed** | Sub-100ms operations; keyboard-first | Slower; heavy configuration | Fast within GitHub | Fast agile boards |
| **Customization** | Low; streamlined defaults | Very high; complex workflows | Moderate (Projects v2) | Moderate; customizable workflow rules |
| **Integrations** | ~40 core dev integrations (GitHub, Slack, Figma, Notion) | 3,000+ across all departments | Native to GitHub; massive Actions marketplace | Smaller ecosystem; JetBrains native |
| **AI Features** | Linear Agent (triage, issue creation from Slack, duplicate detection) | Atlassian Intelligence (summaries, search) | Copilot sold separately | Included at no extra cost |
| **Best For** | Teams that want speed without ticket "religion" | Compliance, audit trails, cross-functional scale | Teams where code ≤→ work is seamless | Teams wanting flat, predictable pricing + on-prem option |

### Competitive Positioning Summary

**Linear** has carved out the "modern default for startups." It raised a $52M Series B at a **$400M valuation in 2022** and reached **40,000+ companies** by 2025, including Vercel and Ramp [https://linear.app/pricing](https://linear.app/pricing) [https://www.youtube.com/watch?v=mtSlmZmTm-s](https://www.youtube.com/watch?v=mtSlmZmTm-s). Its speed advantage is structural — built into the architecture rather than bolted on [https://feedvote.app/blog/linear-app](https://feedvote.app/blog/linear-app).

**Jira** remains the incumbent. While startups complain about its sluggishness, enterprises rely on its cross-functional reach. In response to Linear, Jira launched simplified **"Team-managed"** projects and has continued tightening GitHub integrations, though reviewers note Linear's native GitHub sync remains more bidirectionally responsive [https://tech-insider.org/linear-vs-jira-2026](https://tech-insider.org/linear-vs-jira-2026).

**GitHub Issues + Projects** has evolved from a basic bug tracker into a serious planning layer with boards, custom fields, roadmaps, and sub-issues. It wins when **zero friction between code and tracking** matters [https://octopusbuilds.com/blog/linear-vs-jira-vs-github-issues-ai-driven-development](https://octopusbuilds.com/blog/linear-vs-jira-vs-github-issues-ai-driven-development). However, many teams outgrow it around **500 tickets** and migrate to Linear or Jira for structured workflows [https://cotera.co/articles/linear-vs-github-issues-comparison](https://cotera.co/articles/linear-vs-github-issues-comparison).

**YouTrack** is the value-priced, developer-centric underdog. It is particularly strong in **Eastern Europe, Russia, and among JetBrains IDE users**, offering a full feature set (including AI) at roughly half the per-seat cost of competitors. It also uniquely offers both cloud and self-hosted options without enterprise-only gates [https://resources.rework.com/tools/dev-tools/best-linear-alternatives](https://resources.rework.com/tools/dev-tools/best-linear-alternatives) [https://ones.com/blog/youtrack-vs-jira-pricing-7-point-cost-comparison-for-2026](https://ones.com/blog/youtrack-vs-jira-pricing-7-point-cost-comparison-for-2026).

## Bottom-Line Recommendations

- **Choose Linear** if you are a software team under 300 people using modern tools (GitHub, Slack, Figma) and want speed above all else [https://www.youtube.com/watch?v=vsO3W15YjK0](https://www.youtube.com/watch?v=vsO3W15YjK0).
- **Choose Jira** if you are 500+ engineers, need compliance/audit trails, or must coordinate across multiple non-engineering departments [https://www.youtube.com/watch?v=vsO3W15YjK0](https://www.youtube.com/watch?v=vsO3W15YjK0).
- **Choose GitHub Issues** if your team is small (<20 devs), lives in GitHub, and wants near-zero overhead between code and tracking [https://www.ideaplan.io/compare/github-issues-vs-jira](https://www.ideaplan.io/compare/github-issues-vs-jira).
- **Choose YouTrack** if you want the lowest per-seat cost, need on-premise deployment, or are already embedded in JetBrains IDEs [https://ones.com/blog/youtrack-vs-jira-pricing-7-point-cost-comparison-for-2026](https://ones.com/blog/youtrack-vs-jira-pricing-7-point-cost-comparison-for-2026).
